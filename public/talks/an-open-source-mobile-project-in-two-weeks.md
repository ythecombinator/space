# An open source mobile project in two weeks

- Description: In this talk, I'll share some of the experiences I had while working on Conf App Boilerplate - which aimed to be used to develop the Front In Fortaleza mobile app in two weeks. You'll see how we used trending technologies like Jade, SASS, Typescript, Gulp - and many others -, to help our code gain in aspects of readability and maintainability - and our team, productivity.
